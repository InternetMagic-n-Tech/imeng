# Moving a game from 1.1 to 1.2

No format migration is needed: `schema_version` stays 1 and stored sessions load as they are. Everything new is optional and off by default.

- **Renamed:** `history_limit` (cap on each actor's history) is now `actor_history_limit`. The old name still works; `npm run doctor` warns. The `discord.history_limit` key is unchanged.
- **Added:** `knowledge` (needs `multiplayer`; see `docs/MULTIPLAYER.md` section 11), `too_long_reply`, `wrap_up.turn_budget`.
- **Added (environment, not game.json):** `CONTEXT_MAX_TOKENS`, `CONTEXT_MAX_ROUNDS` (machine guard), `SESSION_SCHEMA`, `SESSION_SCHEMA_SCAN_LIMIT`.
- The shipped games and examples are on 1.2.0 (`proxy_version` in their package.json). Games that use `history_limit` need no edit.
- Also new and optional: `game_turn`, `turn_events`, `private_only_reply`, `private_guidance`, `multiplayer.private.unseated`, `knowledge.notice`, the `<private>` tag (see GAME-MAKING.md).
